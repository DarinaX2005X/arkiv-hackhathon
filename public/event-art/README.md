# Event illustrations

Original SVG artwork authored for Partfolk. Each 600 × 480 scene depicts an event format through a shared family of cream surfaces, forest equipment, an upper-left light source and local contact shadows.

- `gathering.svg`: a shared room and table for in-person or legacy events.
- `online.svg`: a laptop and microphone for online events.
- `hybrid.svg`: a physical gathering space connected to a screen.

These are generic illustrations, not photographs or evidence of actual venues, attendees or equipment. No supplied reference image is included. The files are self-contained, contain no fonts or external resources, and use the repository's license. Edit their source geometry to regenerate them. Cover choice depends only on the existing event format and does not modify public event records or consent hashes.
